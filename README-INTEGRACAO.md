# TechAcademy — Integração do novo design

Arquivos deste pacote:
- dashboard.html
- dashboard.css
- app.js

## Como aplicar

Substitua os três arquivos de mesmo nome na raiz do seu repositório:

1. `dashboard.html`
2. `dashboard.css`
3. `app.js`

O novo `app.js` mantém as funções existentes do dashboard:
- autenticação via `localStorage`
- carregamento do aluno logado
- menu mobile
- cursos disponíveis
- matrícula em curso
- meus cursos
- abertura de curso
- notas
- documentos
- perfil

Além disso, o visual foi reorganizado para o padrão preto + roxo do novo TechAcademy.

Os demais arquivos do projeto (`db.js`, `auth.js`, `cursos-aluno.html`, `perfil.html`, `admin.html`, `gestor.html` etc.) não precisam ser apagados ou substituídos.

## Observação

O pacote é uma camada de integração visual/funcional do dashboard. Ele não altera a estrutura dos dados já armazenados no navegador.
